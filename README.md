# Hairstyle

Simulador capilar em HTML, CSS e JavaScript puro (com WebGL 2). O aplicativo está em `site/`; basta servir a pasta com qualquer servidor estático e abrir `index.html`.

## Limitações

- Sem WebGL 2, o aplicativo exibe uma silhueta 2D.
- Os fluxos de conta, recuperação de senha, contato e inscrição em novidades são demonstrações, sem back-end.
- Os visuais salvos ficam em memória e são descartados ao recarregar a página.
- As fontes vêm do Google Fonts, com fontes de sistema como alternativa.
